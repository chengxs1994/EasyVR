# EasyVR

独立的本地 VR 全景取景、热点漫游与人物空间推演工具。由 EasyDrama 当前工作目录于 2026-10-12 抽离，包含其当时尚未提交的界面与国际化代码快照。原项目未删除或修改；两者以后独立维护。

## 启动

需要 Node.js 18+（推荐 Node.js 22）。

```sh
npm ci
npm run dev
```

默认地址：http://127.0.0.1:5182/ 。无需 AI 服务、API Key 或 EasyDrama 目录。

- `/` 或 `/?panorama=1`：全景取景器。导入 2:1 全景图片、保存取景、导出 PNG、创建多个位置及跳转热点、体验三点漫游。
- `/?tour=home`：项目自带住宅全景浏览。
- `/?editor=1&backdrop=home`：住宅全景背景下的人物站位、走位、灯光、机位与截图。
- `/?editor=1`：独立三维场景编辑器。

## 数据与迁移

全景位置、图片及取景保存在当前浏览器的 IndexedDB `easyvr.panorama`；三维工程使用 `easyvr.spatial.*` localStorage，界面语言使用 `easyvr.ui.language`。素材在本机处理，不上传服务器。

浏览器存储按端口隔离：EasyDrama 原有 5178 端口的数据仍留在那里，不会自动复制到 5182。三维工程可在旧项目导出 JSON，再到 EasyVR 导入；全景取景器暂未实现整套漫游存档导入导出，旧全景位置和热点请继续在旧入口保留，新项目需要重新导入全景图片。不要清除旧站点数据。

全景图片不包含真实房间几何；人物比例和地面需手动校准，背景不支持平移视差、家具遮挡或碰撞。当前住宅图片随项目复制于 `public/panoramas/residential-living-room.jpg`，来源与使用权限沿用原项目，公开发布前请确认素材授权。

## 验证与版本控制

```sh
npm test
npm run build
npm run preview
```

回归覆盖全景角度、画幅、热点、固定拍摄点、地面校准、场景存档、人物动作与导演调度。构建有 Three.js 大体积 chunk 提示，尚未进一步拆分。

本仓库只包含 VR 及其三维依赖，不包含剧本、分集、分镜、生成队列、密钥及服务端。调试默认使用 Codex 内置浏览器。
